# UA Project Manager 1.1.0

Єдиний WordPress-плагін для керування проєктами, платіжними послугами, пошуком сайтів, контактами, email-розсилками та рекламними розміщеннями.

## Єдине джерело даних

- **Проєкти** — головний довідник. Проєкт має стабільний ID, назву, slug, тип і статус.
- **UA Pay Box** — окремі типи послуг: **PRO / ліцензія** та **Розміщення реклами**. Автоматична синхронізація проєктів створює або оновлює тільки PRO-послуги; рекламні послуги не змішуються з ліцензіями.
- **UA Web Finder — збір сайтів** — пошукові та імпортовані списки можна пов’язати з одним або кількома проєктами.
- **UA Web Finder — контакти / розсилки** — списки зібраних email також можна пов’язати з проєктами; кампанії та шаблони зберігаються в наявних таблицях Finder.
- **Синхронізація** — окрема сторінка показує кількість проєктів, послуг Pay Box, списків Finder, сайтів, email і кампаній. Звідти можна вручну повторити зв’язування проєктів з Pay Box.

Зв’язки Finder з проєктами зберігаються за ID, тому перейменування проєкту не руйнує їх. Старі таблиці й записи Pay Box та Finder не очищаються.

## Реклама

Модуль «Реклама» дозволяє:

- створювати рекламодавців із сайтом, email, телефоном, Viber і Telegram;
- створювати кілька рекламних блоків для одного рекламодавця;
- обирати кілька проєктів, для яких дозволено рекламу;
- завантажувати банер або вставляти HTML-код, задавати цільове посилання;
- задавати ціну за місяць, валюту UAH/USD і період розміщення;
- записувати платежі в UAH/USD з типом Freemius, Приват Конверт або готівка;
- рахувати покази та кліки;
- показувати рекламодавця, статистику та дати розміщення у головному списку проєктів;
- надсилати щомісячні звіти рекламодавцям;
- надсилати нагадування за 7 днів і в день завершення розміщення;
- після підтвердженого підписаного webhook Freemius створювати наступний рекламний період і записувати оплату.

### Налаштування рекламного проєкту

У формі проєкту доступні:
- посилання «Всі проєкти» та перемикач відображення;
- HTML banner та перемикач відображення;
- прапорець «Доступний для розміщення реклами»;
- згенеровані shortcode та REST-адреси для WordPress-плагінів і додатків.

Для реклами потрібно створити в Pay Box окрему активну послугу з призначенням **«Розміщення реклами»**, налаштувати Freemius product, plan та secret key, а потім вибрати цю послугу в рекламному блоці. PRO-послуги залишаються окремими.

## Оновлення

Файл .github/workflows/auto-release.yml читає Version з головного PHP-файлу, перевіряє наявність відповідного tag, збирає ZIP та публікує GitHub Release. WordPress updater бере останній опублікований release з цього репозиторію.

Публічне посилання на завантаження останньої версії:
https://github.com/portallcomua/ua-project-manager/releases/latest/download/ua-project-manager.zip

Версійні ZIP та нотатки релізу:
https://github.com/portallcomua/ua-project-manager/releases/latest

Ручне складання ZIP доступне через GitHub Actions → Manual plugin ZIP build.

## Безпечне оновлення

Не видаляйте окремі UA Pay Box та UA Web Finder, доки не перевірено перенесення всіх робочих сценаріїв на вбудовані модулі. Вбудований модуль використовує ті самі таблиці й опції, але остаточну поведінку треба перевіряти на робочому сайті.

## Перевірки перед публікацією

1. PHP syntax check для всіх PHP-файлів (PHP 7.4).
2. Перевірка складання ZIP та його структури.
3. Перевірка оновлення через GitHub Release.
4. Ручна перевірка на тестовому WordPress: проєкти, Pay Box, пошук, email-списки, кампанії, рекламні блоки, звіти та webhook Freemius.
