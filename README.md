# UA Project Manager 1.1.17

Самостійний WordPress-плагін для керування проєктами, клієнтами, платежами, ліцензіями, рекламою, пошуком сайтів, контактами, email-розсилками, завантаженнями та інтеграціями.

## Автономна робота

UA Project Manager містить власні вбудовані модулі:

- **Pay Box** — послуги, PRO-ліцензії, Freemius, платежі та перевірка оплат.
- **Web Finder** — пошук сайтів за CMS, імпорт доменів, списки, збір контактів і email-розсилки.
- **Click Counter** — кнопки, переходи та статистика кліків.

Для роботи цих модулів **не потрібно встановлювати або активувати окремі UA Pay Box, UA Finder, CMS Finder чи CMS Web Finder**. Код модулів, адміністративні сторінки, обробники та ресурси постачаються всередині цього репозиторію.

Зовнішні сервіси, наприклад Freemius або GitHub API, використовуються лише для відповідних додаткових функцій і не є WordPress-плагінами, необхідними для запуску основної системи.

## Єдине джерело даних

- **Проєкти** — головний довідник зі стабільними ID, назвами, slug, типом і статусом.
- **Платежі та ліцензії** — облік фактично отриманих сум, часткових оплат і доступу.
- **Pay Box** — вбудований платіжний модуль. Проєкти можуть синхронізуватися з послугами автоматично.
- **Web Finder** — вбудований пошук та імпорт сайтів; списки сайтів, контакти й кампанії можна пов'язувати з проєктами.
- **Реклама** — рекламодавці, блоки, періоди, оплати, покази, кліки та звіти.
- **Синхронізація** — зв'язки між проєктами та внутрішніми модулями.

Старі таблиці й записи Pay Box та Web Finder зберігаються для сумісності під час оновлення. Їхня наявність не означає залежності від окремих плагінів.

## Навігація

Адміністративні розділи реєструються самим UA Project Manager та його вбудованими модулями. Навігація використовує внутрішні slug сторінок; неактуальні маршрути, для яких немає сторінки, не повинні показуватися як робочі посилання.

## Реклама

Модуль «Реклама» дозволяє:

- створювати рекламодавців із сайтом, email, телефоном, Viber і Telegram;
- створювати кілька рекламних блоків для одного рекламодавця;
- обирати проєкти, для яких дозволено рекламу;
- завантажувати банер або вставляти HTML-код і задавати цільове посилання;
- задавати ціну за місяць, валюту UAH/USD і період розміщення;
- записувати платежі з типом Freemius, Приват Конверт або готівка;
- рахувати покази та кліки;
- надсилати щомісячні звіти та нагадування про завершення розміщення;
- створювати наступний рекламний період після підтвердженого підписаного webhook Freemius.

Для оплати через Freemius потрібно налаштувати відповідні Product ID, Plan ID та Secret Key у вбудованому Pay Box. Без налаштування Freemius ручний облік платежів залишається доступним.

## Оновлення

WordPress updater використовує GitHub Release цього репозиторію. Версія та ZIP беруться з останнього стабільного релізу; основний файл пакета — `ua-project-manager.zip`.

Публічне посилання на завантаження останньої версії:

https://github.com/portallcomua/ua-project-manager/releases/latest/download/ua-project-manager.zip

Сторінка останнього релізу:

https://github.com/portallcomua/ua-project-manager/releases/latest

Ручне складання ZIP доступне через GitHub Actions → Manual plugin ZIP build.

## Вимоги

- WordPress 6.0 або новіший.
- PHP 7.4 або новіший.
- MySQL 5.7 або MariaDB сумісної версії.
- HTTPS рекомендовано для захищених інтеграцій і webhook.

## Перевірки перед публікацією

1. PHP syntax check для всіх PHP-файлів.
2. Перевірка складання ZIP та його структури.
3. Перевірка оновлення через GitHub Release.
4. Ручна перевірка на тестовому WordPress: проєкти, платежі, ліцензії, вбудований Pay Box, пошук, email-списки, кампанії, рекламні блоки, звіти та webhook Freemius.
5. Перевірка всіх внутрішніх посилань під обліковими записами адміністратора та менеджера.
